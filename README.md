# Manoj Karthik Chinniah — Portfolio

Static portfolio based on the supplied HTML. No build step or dependencies are required.

## Publish with GitHub Pages

1. Create a public GitHub repository named `portfolio` (or use an existing repository).
2. Upload `index.html` and `.nojekyll` to the root of the `main` branch.
3. Open **Settings → Pages**, select **Deploy from a branch**, select **main** and **/ (root)**, and save.
4. Wait for the Pages deployment to finish. GitHub shows the published URL in **Settings → Pages**.

For a repository named `portfolio`, the address is `https://YOUR-USERNAME.github.io/portfolio/`. This is a template, not a confirmed live URL.

Edit `index.html` to update the portfolio. Changes published to the selected branch are deployed automatically.
